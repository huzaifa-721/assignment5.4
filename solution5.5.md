I chose a consistent dark navy #0a192f as primary and cyan #00b4d8 as secondary with mint accent #64ffda for a modern tech club look. I used Segoe UI font family for both headings and body to maintain clean readability and consistent typography. Navigation is styled with hover effects and active state for better UX. I made tables and forms highly readable with proper padding, focus states, and alternating row colors. I kept CSS clean and reusable by using :root variables for colors, spacing, and font sizes, grouping selectors, and using one external stylesheet for all four pages, which I debugged using Chrome DevTools.
